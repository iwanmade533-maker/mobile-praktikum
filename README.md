# Aplikasi To-Do List

## Deskripsi

Aplikasi To-Do List sederhana yang dibuat menggunakan Flutter
sebagai latihan pemrograman mobile. Aplikasi ini digunakan untuk
mencatat dan mengelola tugas sehari-hari.

## Tujuan

Tujuan aplikasi ini adalah membantu pengguna mencatat tugas
yang perlu dilakukan secara sederhana dan terorganisir.
Aplikasi ini juga digunakan sebagai latihan dalam mempelajari
pengembangan aplikasi mobile menggunakan Flutter.

## Rencana Fitur

1. Menambah tugas
2. Melihat daftar tugas
3. Menghapus tugas

## Cara Menjalankan

Pastikan Flutter sudah terpasang dan dapat digunakan pada
lingkungan pengembangan.

Jalankan perintah berikut pada terminal:

```bash
flutter pub get
flutter run
